# chrome-pet
크롬 확장프로그램용 펫 키우기 프로젝트

## 실행

```sh
npm install
npm run build
```

Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램 로드**로 `dist/`를 선택합니다.
업데이트 후에는 확장 프로그램을 다시 로드하고 기존 웹페이지도 새로고침해야 합니다.

## 탭 간 공유

- 같은 Chrome 프로필의 탭은 펫 종류, 애정도, 위치, 방향, 이동 상태, 드래그, 나비 잡기 및 쓰다듬기 효과를 공유합니다.
- 백그라운드 서비스 워커가 이동과 행동을 계산하고 각 탭은 같은 상태를 표시합니다.
- 창 크기가 다르면 위치를 화면 내 비율로 맞춥니다.
- 한 탭에서 펫을 교체하면 다른 탭의 펫과 진행 중인 뽑기도 함께 갱신됩니다.
- 저장 요청은 백그라운드에서 순서대로 처리하며, 교체 전 펫에 대한 오래된 요청은 거절합니다.
- 보이는 탭이 없으면 이동을 일시정지합니다. 위치는 세션 저장소에 보관해 워커 재시작 시 복원하고, 보유 펫과 애정도는 로컬 저장소에 영구 보관합니다.
- `chrome://` 등 확장 콘텐츠 스크립트가 실행되지 않는 페이지에서는 표시되지 않습니다.

## 개발 및 검증

```sh
npm run typecheck
npm run build
```

개발 중에는 첫 빌드 후 `npm run dev`, `npm run dev:background`, `npm run dev:popup`을 각각 실행합니다.
